### create_blueprint:
Design the architecture of the full-stack application before writing any code.
This includes:
- Frontend components and state management.
- Backend API endpoints and logic.
- Database schema and relationships.
- Authentication and security flow.
- Deployment strategy.

usage:
~~~json
{
    "thoughts": [
        "I need to design the full-stack architecture for...",
    ],
    "headline": "Designing full-stack architecture",
    "tool_name": "create_blueprint",
    "tool_args": {
        "name": "app_architecture",
        "content": "# App Architecture\n\n## Tech Stack\n- Frontend: React/Next.js\n- Backend: FastAPI\n- DB: PostgreSQL\n\n## Components\n- ...\n\n## API Endpoints\n- ..."
    }
}
~~~
