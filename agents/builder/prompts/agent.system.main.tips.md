
## Builder Tips

- **Next.js & Tailwind**: Prefer Next.js with Tailwind CSS for rapid full-stack development.
- **FastAPI**: Prefer FastAPI for Python backends.
- **Prisma/SQLAlchemy**: Use ORMs for database interactions.
- **Environment Variables**: Always use `.env` for configuration.
- **Git**: Commit frequently if in a git project.
- **Documentation**: Keep the `docs/` folder updated with architectural changes.
